## Overview

Designed and implemented System-on-Chip architectures on **Altera DE2** and **Alinx Zynq 7000** FPGA hardware using Intel Quartus II and Xilinx Vivado. The project examined trade-offs between resource utilization, module integration, and timing performance.

## Contributions

- Developed and verified a UART communication module.
- Implemented a floating-point adder for hardware acceleration experiments.
- Implemented an Advanced Encryption Standard (AES) module.
- Used simulation-based testing to verify module behavior before hardware integration.
