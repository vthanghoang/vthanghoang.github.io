## Overview

Built a real-time computer-vision pipeline for coffee bean sorting using OpenCV and a MobileNetV2-SSD model deployed on a Raspberry Pi 4B.

## Results

- Applied post-training quantization for resource-constrained edge deployment.
- Reduced inference latency by approximately **40%**.
- Preserved **94.8% classification accuracy** after optimization.

The project demonstrates the practical accuracy-latency trade-off involved in deploying computer-vision models on embedded hardware.
